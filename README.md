# Quasar Frontend

Vue 3, Vite va Quasar Framework asosidagi frontend loyiha.

## Ishga tushirish

Dependency'larni o'rnatish:

```sh
npm install
```

Development server:

```sh
npm run dev
```

Production build va type-check:

```sh
npm run build
```

Quasar Vite plugin `vite.config.ts`da, Quasar initialization esa `src/main.ts`da sozlangan. UI komponentlari
`src/App.vue`dagi `QLayout` asosida qurilgan.
